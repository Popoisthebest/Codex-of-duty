Review the map as a competitive 6v6 combat space.

Do not edit implementation files.

Evaluate:
- scale without emptiness
- zone identity
- route families
- route loops
- flank viability
- indoor/outdoor transitions
- verticality
- sightline lengths
- cover rhythm
- spawn depth/safety
- travel time
- encounter concentration
- landmarks/navigation

Reject dimension padding, fake lanes and decorative dead space.

When possible, use screenshots, map metadata, source geometry and runtime evidence together.

Return the highest-impact layout failure first and define a measurable acceptance target.
