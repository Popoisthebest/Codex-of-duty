# One-Prompt Examples

하네스가 설치된 뒤에는 프롬프트를 길게 만들 필요가 없습니다.

## 기능

```text
사용자가 프로필 사진을 업로드하고 크롭한 뒤 저장할 수 있게 구현해줘.
```

## UI

```text
현재 대시보드 UI를 더 완성도 높은 SaaS 제품 수준으로 개선해줘. 기존 기능은 모두 유지해.
```

## 버그

```text
새로고침하면 장바구니 수량이 초기화되는 문제를 찾아서 해결해줘.
```

## 대회/제출

```text
현재 시뮬레이션을 최종 제출 가능한 상태로 완성해줘. 실제로 실행해서 핵심 실험이 정상적으로 가능한지 검증하고 발견되는 문제도 수정해.
```

## 큰 기능

```text
관리자가 사용자 목록을 검색하고 계정을 비활성화할 수 있는 관리 화면과 API를 구현해줘.
```

하네스가 해야 할 검증 절차를 매번 프롬프트에 반복하지 않는 것이 목적입니다.
